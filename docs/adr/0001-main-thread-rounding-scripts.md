# Выполнение скриптов скругления в основном потоке

Пользовательские скрипты скругления выполняются как произвольный JavaScript в основном потоке без sandbox, worker или таймаута, чтобы не ограничивать доступный автору язык. Пользователь принимает риск зависания страницы и побочных действий скрипта; код из импортированного QR-профиля остаётся выключенным до явного разрешения.
