# Трекер задач: локальный Markdown

Задачи и спецификации этого репозитория хранятся в `.scratch/`.

## Соглашения

- Одна функция на каталог: `.scratch/<feature-slug>/`
- Спецификация: `.scratch/<feature-slug>/spec.md`
- Задачи реализации: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, начиная с `01`
- Статус triage записывается строкой `Status:` в начале файла
- Комментарии добавляются в конец файла под заголовком `## Comments`

## Публикация

Если skill говорит «опубликовать в трекере задач», создай новый файл в `.scratch/<feature-slug>/`.

## Поиск задач

При запросе конкретной задачи прочитай файл по указанному пути или номеру.

## Операции wayfinder

- Карта: `.scratch/<effort>/map.md`
- Дочерняя задача: `.scratch/<effort>/issues/NN-<slug>.md`
- Тип задачи указывается строкой `Type:` (`research`, `prototype`, `grilling`, `task`)
- Статус задачи указывается строкой `Status:` (`claimed`, `resolved`)
- Блокировки указываются строкой `Blocked by: NN, NN`
- Первой выбирается открытая, разблокированная и незаявленная задача с наименьшим номером
- При завершении ответ добавляется под `## Answer`, затем ссылка на решение добавляется в `map.md`
