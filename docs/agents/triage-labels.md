# Triage-метки

| Каноническая роль | Метка в репозитории | Значение                              |
| ----------------- | ------------------- | ------------------------------------- |
| `needs-triage`    | `needs-triage`      | Требуется оценка сопровождающего      |
| `needs-info`      | `needs-info`        | Ожидается дополнительная информация   |
| `ready-for-agent` | `ready-for-agent`   | Полностью описано и готово для агента |
| `ready-for-human` | `ready-for-human`   | Требует реализации человеком          |
| `wontfix`         | `wontfix`           | Не будет реализовано                  |
