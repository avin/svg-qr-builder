# Доменные документы

Перед исследованием области прочитай:

- `CONTEXT.md` в корне; если существует `CONTEXT-MAP.md`, используй его для поиска нужного контекста
- ADR в `docs/adr/`, относящиеся к рассматриваемой области

Если этих файлов нет, продолжай работу без предупреждений — они создаются skill-ами моделирования домена по мере необходимости.

## Структура

Репозиторий использует одноконтекстную схему:

- `/CONTEXT.md`
- `/docs/adr/`
- `/src/`

## Терминология

В названиях задач, предложениях по рефакторингу и тестах используй термины из `CONTEXT.md`. Если нужного термина там нет, зафиксируй это как пробел доменной модели.

## Конфликты ADR

Если решение противоречит существующему ADR, явно укажи это, а не переопределяй ADR молча.
