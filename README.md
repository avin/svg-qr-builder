# React app template

Минимальный React-проект для разработки новой страницы.

## Команды

| Команда             | Описание                            |
| ------------------- | ----------------------------------- |
| `npm run dev`       | Dev-сервер (https://localhost:8888) |
| `npm run build`     | Сборка                              |
| `npm run check`     | Все обязательные быстрые проверки   |
| `npm run typecheck` | Проверка типов                      |
| `npm run lint`      | Линт (oxlint)                       |
| `npm run format`    | Форматирование (oxfmt)              |
| `npm run test:unit` | Юнит-тесты (vitest)                 |
| `npm run test:e2e`  | E2E (Playwright)                    |
| `npm run storybook` | Storybook (https://localhost:8889)  |

## Стек

React 19, TypeScript, Vite, Redux Toolkit, i18next, Tailwind CSS, SCSS-модули, Storybook, Vitest, Playwright.

Tailwind — только для утилитарных классов; основные стили — в SCSS-модулях.
