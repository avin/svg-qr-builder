# 07: Проверка сканируемости результата

**What to build:** Пользователь после каждой успешной генерации видит результат автоматической попытки декодировать окончательный QR-код и может осознанно скачать его даже при предупреждении.

**Blocked by:** 04 / Завершённое SVG-представление; 06 / Центральное изображение с модульным вырезом.

**Status:** ready-for-agent

- [ ] После стабилизации настроек проверяется именно итоговый SVG с foreground, фоном, тихой зоной и центральным изображением.
- [ ] Во время проверки отображается доступный локализованный статус без блокировки редактирования.
- [ ] Успешная проверка подтверждает, что декодированная строка точно равна полезной нагрузке.
- [ ] Неудача, исключение декодера или несовпадение строки показываются как заметное предупреждение, а не как гарантия физической нечитаемости.
- [ ] Предыдущая асинхронная проверка не может перезаписать статус более нового результата.
- [ ] Предупреждение декодера не блокирует скачивание и копирование успешного SVG.
- [ ] Ошибка самой генерации по-прежнему блокирует действия экспорта и не запускает проверку.
- [ ] Статус и результат проверки являются производными данными и не входят в QR-профиль или рабочий черновик.
- [ ] Граница декодера имеет заменяемый публичный контракт для детерминированных интеграционных тестов.
- [ ] Vitest или Testing Library покрывает success, mismatch, unreadable, exception и гонку устаревшего результата.
- [ ] Все статусы переведены на английский, русский и арабский и объявляются вспомогательным технологиям без навязчивого повторения.
- [ ] Все обязательные проверки исполняемого кода, сборки и пользовательского flow проходят.
