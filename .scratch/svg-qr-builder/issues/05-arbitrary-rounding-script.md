# 05: Произвольный скрипт скругления

**What to build:** Пользователь пишет полноценную JavaScript-функцию для `resolveCornerRadius`, сразу видит её эффект и получает устойчивое состояние редактора при исправимых ошибках.

**Blocked by:** 03 / Полная настройка геометрии QR-кода.

**Status:** ready-for-agent

- [ ] Редактор принимает исходный текст полноценной функции `(context) => number | undefined` без ограничений синтаксиса JavaScript.
- [ ] Рядом доступен локализованный справочник `region`, `block`, `part`, `contour`, `corner`, `vertex`, `cell` и `defaultRadius`, а также рабочие примеры.
- [ ] Функция компилируется и выполняется в основном потоке без sandbox, worker и таймаута в соответствии с ADR.
- [ ] Возвращённые число и `undefined` передаются в контракт `sexy-qr`; библиотечная ошибка недопустимого результата становится пользовательской диагностикой.
- [ ] Синтаксическая ошибка и исключение выполнения показывают локализованное сообщение и доступное местоположение в исходнике, когда его можно определить.
- [ ] После ошибки остаётся последнее успешно построенное превью, явно помеченное как устаревшее.
- [ ] При ошибке скрипта скачивание и копирование отключены до следующей успешной генерации.
- [ ] Очистка редактора возвращает стандартные радиусы без callback.
- [ ] Vitest покрывает число, `undefined`, ветвление по контексту, синтаксическую ошибку, исключение и недопустимый результат; бесконечный цикл не запускается.
- [ ] Testing Library покрывает успешную правку, ошибку, устаревшее превью, исправление и восстановление действий экспорта.
- [ ] Все новые тексты переведены на английский, русский и арабский и доступны с клавиатуры.
- [ ] Все обязательные проверки исполняемого кода, сборки и пользовательского flow проходят.
