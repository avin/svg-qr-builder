# 01: Первый рабочий SVG QR-код

**What to build:** Пользователь получает первый законченный вертикальный путь: открывает редактор с рабочим примером, меняет полезную нагрузку и основные параметры, сразу видит QR-код и скачивает SVG.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Установлены Base UI и точно зафиксированная версия `sexy-qr@2.0.0`; npm lockfile соответствует зависимостям.
- [ ] При первом открытии полезная нагрузка равна `https://github.com/avin/sexy-qr`, ECL равен `M`, размер матрицы равен 512 px, применён preset `roundedWithCircleCornerBlocks`, а foreground имеет согласованный графитовый цвет.
- [ ] Пользователь может изменить полезную нагрузку, ECL, размер и foreground через кастомные React-компоненты на основе Base UI.
- [ ] Превью обновляется автоматически примерно через 150 мс после стабилизации ввода без отдельной кнопки генерации.
- [ ] Пустая или неподдерживаемая полезная нагрузка показывает доступную диагностическую ошибку и отключает скачивание.
- [ ] Успешный результат отображается как SVG и скачивается в виде `.svg` с корректным MIME type.
- [ ] Интерактивные элементы имеют семантические роли, доступные имена, видимый фокус и работают с клавиатуры.
- [ ] Назначение созданных общих компонентов отражено в каталоге общих компонентов.
- [ ] Контракт «основные настройки → SVG или диагностическая ошибка» покрыт Vitest с реальной `sexy-qr`.
- [ ] Основной пользовательский путь ввода и скачивания покрыт Testing Library и Playwright.
- [ ] Все обязательные проверки исполняемого кода, сборки и пользовательского flow проходят.
