# 02: Локализованный адаптивный редактор

**What to build:** Пользователь получает полностью переведённую и адаптивную оболочку редактора, которая выбирает подходящий язык, сохраняет предпочтение и естественно работает в LTR и RTL.

**Blocked by:** 01 / Первый рабочий SVG QR-код.

**Status:** ready-for-agent

- [ ] Весь существующий пользовательский текст доступен на английском, русском и арабском языках без непереведённых fallback-ключей.
- [ ] Сохранённый выбор языка имеет приоритет над языком браузера; `ru-*` выбирает русский, `ar-*` выбирает арабский, остальные локали выбирают английский.
- [ ] Английский является fallback-языком для отсутствующих и неизвестных локалей.
- [ ] В правой части шапки расположен доступный кастомный компонент выбора языка.
- [ ] Выбранный язык сохраняется в `localStorage` как общая настройка приложения и восстанавливается после перезагрузки.
- [ ] Корневые `lang` и `dir` синхронизируются с выбранной локалью; полезная нагрузка не подвергается bidi-преобразованию.
- [ ] Desktop-компоновка показывает прокручиваемые группы настроек рядом с липким крупным превью.
- [ ] Mobile-компоновка показывает компактное липкое превью над раскрывающимися группами настроек.
- [ ] Направленные элементы и порядок компоновки зеркалятся в RTL с помощью логических свойств, не ломая ввод и SVG-превью.
- [ ] Testing Library покрывает приоритет выбора языка, сохранение, fallback и смену `lang`/`dir`.
- [ ] Playwright подтверждает основной мобильный сценарий на арабском языке, клавиатурную доступность и отсутствие перекрытий критических действий.
- [ ] Все обязательные проверки исполняемого кода, сборки и пользовательского flow проходят.
