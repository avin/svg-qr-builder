# 04: Завершённое SVG-представление

**What to build:** Пользователь оформляет foreground, фон и тихую зону, а затем скачивает или копирует законченный безопасный SVG, соответствующий превью.

**Blocked by:** 02 / Локализованный адаптивный редактор.

**Status:** ready-for-agent

- [ ] Foreground задаётся через кастомный color picker и текстовое поле с поддержкой HEX, RGB, HSL, именованных CSS-цветов и `currentColor`.
- [ ] Некорректный CSS-цвет, `url(...)`, произвольный атрибут или SVG-разметка отклоняются до генерации.
- [ ] Пользователь может выбрать цветной либо прозрачный фон; исходный фон белый.
- [ ] Пользователь может задать неотрицательную тихую зону в QR-модулях; исходное значение равно 4 модулям.
- [ ] Превью, скачанный файл и скопированный код используют один и тот же итоговый SVG с foreground, фоном и тихой зоной.
- [ ] SVG имеет корректный viewBox и размеры после добавления тихой зоны и не обрезает матрицу.
- [ ] Копирование использует Clipboard API и показывает доступное подтверждение либо понятную ошибку недоступности.
- [ ] Скачивание создаёт `.svg` с корректным MIME type и Unicode-safe содержимым.
- [ ] Все новые подписи, статусы и ошибки переведены на английский, русский и арабский.
- [ ] Vitest покрывает цветной и прозрачный фон, тихую зону, допустимые форматы цвета и отклонение небезопасного fill.
- [ ] Testing Library покрывает настройку, копирование, ошибку Clipboard API и равенство пользовательски наблюдаемого результата превью и экспорта.
- [ ] Все обязательные проверки исполняемого кода, сборки и пользовательского flow проходят.
