# 06: Центральное изображение с модульным вырезом

**What to build:** Пользователь загружает центральное изображение без преобразования, настраивает его относительный размер и padding, а приложение пропорционально размещает его в вырезанной библиотекой области QR-кода.

**Blocked by:** 04 / Завершённое SVG-представление.

**Status:** ready-for-agent

- [ ] Компонент загрузки принимает один файл размером не больше 1 048 576 байт и показывает понятную ошибку при превышении на один байт.
- [ ] Приложение не сжимает, не масштабирует, не конвертирует и не меняет анимацию принятого файла.
- [ ] Принимается формат, который текущий браузер способен декодировать как SVG `<image>`; недекодируемый файл отклоняется.
- [ ] Загруженный SVG очищается от активного содержимого, обработчиков событий, внешних ссылок и иных небезопасных конструкций.
- [ ] Intrinsic width и height определяются до генерации; отсутствие размеров или ошибка декодирования показываются пользователю.
- [ ] Один процент ограничивает длинную сторону с сохранением пропорций, имеет диапазон 5–40% и исходное значение 25%.
- [ ] Значение больше 30% показывает предупреждение, но остаётся доступным.
- [ ] Padding задаётся от 0 до 4 модулей с шагом 0,5, начинается с 0,5 и не меняет видимый размер изображения.
- [ ] Интерфейс показывает фактические размеры прямоугольного выреза после округления к целым модулям.
- [ ] `emptyCenter(width, height)` вызывается до создания SVG, а приложение использует content hook только для сформированного им безопасного `<image>`.
- [ ] При добавлении изображения предлагается ECL `H`, но пользователь может сохранить любое значение.
- [ ] Пользователь может удалить изображение и полностью восстановить матрицу без изменения остальных настроек.
- [ ] Vitest покрывает квадратные, альбомные и портретные пропорции, граничные проценты, padding, округление, безопасную вставку и очистку SVG.
- [ ] Testing Library покрывает загрузку, ошибки, предупреждения, рекомендацию `H`, настройку и удаление изображения.
- [ ] Все новые тексты переведены на английский, русский и арабский; обязательные проверки проекта проходят.
