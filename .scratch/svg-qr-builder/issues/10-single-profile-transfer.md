# 10: Перенос одного QR-профиля через файл

**What to build:** Пользователь экспортирует один законченный QR-профиль, переносит файл на другой компьютер и импортирует его как безопасную независимую копию со всеми настройками и изображением.

**Blocked by:** 09 / Библиотека QR-профилей.

**Status:** ready-for-agent

- [ ] За одну операцию экспортируется только один выбранный QR-профиль; массовый экспорт библиотеки отсутствует.
- [ ] Экспортируемый JSON имеет версионированный envelope и содержит полный snapshot, script source, image Data URL и необходимые метаданные формата.
- [ ] Локальный статус доверия скрипту не входит в экспортируемый файл.
- [ ] За одну операцию импортируется только один QR-профиль; envelope, версия, типы, границы, размер изображения и Data URL валидируются до изменения библиотеки.
- [ ] Повреждённый, несовместимый или недопустимый файл показывает локализованную ошибку и не создаёт частичный профиль.
- [ ] Импорт всегда создаёт новый внутренний ID и никогда не перезаписывает существующий QR-профиль.
- [ ] При конфликте имени автоматически добавляется понятный уникальный суффикс.
- [ ] Центральное изображение после импорта визуально совпадает с экспортированным и остаётся частью нового QR-профиля.
- [ ] Импортированный script source показывается пользователю как данные и остаётся выключенным до явного разрешения.
- [ ] Явное разрешение применяется только к локальной копии конкретного QR-профиля; отказ сохраняет профиль с выключенным скриптом.
- [ ] Импорт и экспорт доступны с клавиатуры и работают в актуальных desktop- и mobile-браузерах, поддерживающих соответствующие файловые API.
- [ ] Vitest покрывает round trip, несовместимую версию, повреждение, новый ID, конфликт имени, изображение и отсутствие trust metadata.
- [ ] Testing Library и Playwright подтверждают перенос одного QR-профиля через реальный файл и отдельное разрешение импортированного скрипта.
- [ ] Все новые тексты переведены на английский, русский и арабский; обязательные проверки проекта проходят.
