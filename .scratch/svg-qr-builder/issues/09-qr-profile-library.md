# 09: Библиотека QR-профилей

**What to build:** Пользователь создаёт и поддерживает именованные QR-профили, безопасно переключается между ними и всегда может вернуться к неизменяемому встроенному варианту.

**Blocked by:** 08 / Восстанавливаемый рабочий черновик.

**Status:** ready-for-agent

- [ ] Пользователь может создать QR-профиль через «Сохранить как» из любого валидного рабочего черновика.
- [ ] Имена QR-профилей обязательны и уникальны без учёта регистра; конфликт показывает локализованную ошибку без потери черновика.
- [ ] «Сохранить» обновляет выбранный пользовательский QR-профиль только после явного действия.
- [ ] QR-профиль является полным versioned snapshot настроек, script source и image Data URL.
- [ ] Встроенный QR-профиль нельзя перезаписать или удалить; его рабочий черновик можно редактировать, сбросить и сохранить как новый профиль.
- [ ] Пользователь может выбрать другой QR-профиль и увидеть точно сохранённый результат.
- [ ] При смене профиля с грязным черновиком диалог предлагает сохранить, отбросить изменения или остаться; каждая ветвь выполняет заявленное действие.
- [ ] Пользователь может удалить пользовательский QR-профиль; удаление активного профиля переключает редактор на встроенный вариант.
- [ ] Последний активный профиль и связанный рабочий черновик восстанавливаются после перезагрузки.
- [ ] Переполнение хранилища не удаляет и не частично перезаписывает библиотеку QR-профилей.
- [ ] Управление профилями доступно с клавиатуры, корректно работает на mobile и зеркалится в RTL.
- [ ] Testing Library покрывает создание, сохранение, уникальность, выбор, все ветви грязного диалога, удаление, сброс и ограничения встроенного профиля.
- [ ] Playwright подтверждает создание пользовательского QR-профиля и его восстановление после перезагрузки.
- [ ] Все новые тексты переведены на английский, русский и арабский; обязательные проверки проекта проходят.
