# Локализация

Применяй каждое правило ниже к каждому затронутому тексту и файлу перевода. Публичный API — `loadLocale` / `changeLanguage`; чанки собирает `vite/plugins/i18n/i18n-split-plugin.ts`.

- `src/i18n/languages.ts` — единый источник списка языков и их направлений. При добавлении языка обнови `languages` и `languageDirections`; компоненты берут направление из общего i18n-механизма.
- Core-тексты храни в `src/i18n/translations/index.ts`. Тексты плагина — только в `src/plugins/<plugin-id>/translations.ts`; Vite подключает их namespace лишь для выбранного банковского preset. Locale-файлы и чанки вручную не создавай.
- Локали загружай через `loadLocale` / `changeLanguage` и virtual modules сплит-плагина.
- При смене языка синхронизируй `lang` и `dir` корневого `<html>` через общий i18n-механизм. Способ выбора, автоопределения и сохранения языка оставляй владельцу целевого приложения.
- Для каждого нового текста добавляй значения всех языков из `languages.ts`. Namespace плагина совпадает с его id и передаётся в `useTranslation("plugin-id")`.
- Ключ перевода — короткий английский вариант фразы в lower camelCase.
- В ключе оставляй смысл фразы: опускай артикли и неключевые слова (`maximumTransferAmount`, `saveCard`, `payFewTaps`). Ключ называй по смыслу фразы, а не по компоненту, теме, месту или UI-роли.
- Если одинаковый текст уже существует, переиспользуй его ключ.
- Компонент-владелец пользовательской фразы вызывает `t("key")`; общий компонент принимает локализованный текст через props или `children`.
- Для внешнего или пользовательского текста, направление которого может отличаться от языка интерфейса, используй bidi-изоляцию или `dir="auto"` на минимально необходимом контейнере.
