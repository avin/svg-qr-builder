# react-app-template

Минимальный шаблон React-приложения с Redux Toolkit, i18next, SCSS Modules, Vitest и Playwright.

## Правила проекта

- Используй npm. Изменение зависимостей завершай обновлением `package-lock.json`.
- Язык: комментарии, документация и названия тестов в проекте — на русском. Всё остальное — строго на английском.
- Общий UI — каталог `src/components/common/COMPONENTS.md`: перед работой смотри, что уже есть; при создании компонента или изменении его устойчивого назначения обнови краткую запись. Каталог описывает только назначение и публичную роль компонентов; детали реализации, хуки и частные браузерные обходы туда не добавляй. Обычные изменения реализации без изменения назначения записи каталога не требуют.
- UI должен работать в LTR и RTL; направление задаёт выбранный язык.
- Редактируй исходники; `dist`, `storybook-static` и отчёты тестов считай сгенерированными.

## Правила кода

- Для приведения значения к boolean в исходном коде предпочитай оператор `!!` вызову `Boolean()`.

## Проверка перед завершением

Запусти все проверки, соответствующие изменению:

- Исполняемый код: `npm run check`.
- Сборка, Vite-конфиг или точки входа: дополнительно `npm run build`.
- Пользовательский флоу (действия, форма, навигация, язык или валидация): дополнительно `npm run test:e2e`.
- Только документация или инструкции: `npm run format:check`.

## Agent skills

### Issue tracker

Задачи и спецификации хранятся в локальных Markdown-файлах под `.scratch/`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Используются стандартные triage-метки: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. См. `docs/agents/triage-labels.md`.

### Domain docs

Одноконтекстная схема: `CONTEXT.md` в корне и ADR в `docs/adr/`. См. `docs/agents/domain.md`.
